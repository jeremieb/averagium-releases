# 1.0.25

****

**Added**
- Comments for features and bugs. Add Markdown notes when creating or editing either item; they appear when the item is expanded in the project view.
- Expandable bug cards, making it easier to review bug details without leaving the project view.
- Project context actions in the sidebar and Overview. Right-click a project to edit it, add a feature, task, or bug, or remove it from Averagium. Removing a project keeps its repository and Markdown files on disk.
